# מד סיכון הפסקת האש — איראן / ארה״ב

דשבורד חי (ללא בנייה, HTML+JS סטטי) שמציג ציון משוקלל להסתברות
להתפוצצות הפסקת האש בין איראן לארה״ב על-בסיס אינדיקטורים פתוחים.

## הרצה
פתחו את `index.html` ישירות בדפדפן, או הריצו שרת סטטי:

```bash
python3 -m http.server 8000
# גישה: http://localhost:8000
```

## פרמטרים במודל (משקלות)

| קטגוריה | משקל | מקור תצפית |
|--------|:---:|-----------|
| נוכחות ימית (נושאות, משחתות, ARG) | 20% | USNI Fleet Tracker, AIS |
| תעופה אסטרטגית (B-52/B-2, KC-135/46, C-17) | 20% | ADS-B Exchange, FlightRadar24 |
| פעילות פרוקסי (חות׳ים/חיזבאללה/מיליציות) | 15% | דיווחי מבצעים |
| רטוריקה דיפלומטית ואיומים רשמיים | 15% | הצהרות רשמיות |
| התקדמות גרעינית והעשרה | 10% | סבא״א |
| תנודתיות שוק האנרגיה (Brent/WTI/OVX) | 10% | EIA, CBOE |
| התרעות טילים / רחפנים | 10% | פיקוד העורף / CENTCOM |

## אזהרה
הנתונים בגרסה זו מסומלצים דטרמיניסטית לפי הזמן הנוכחי.
לחיבור נתונים חיים יש להחליף את `data.js` בקריאות API חיות
(MarineTraffic, ADS-B Exchange, EIA, NewsAPI, וכד׳).
